# Critic Workflow

1. Restate the proposal, plan, or current result being challenged.
2. List assumptions that would break the result if false, including social, operational, security, and maintenance assumptions.
3. Identify concrete failure modes with trigger, impact, likelihood, and detection signal.
4. Check for over-delegation, overengineering, prompt-injection exposure, weak validation, and irreversible decisions.
5. Recommend smaller alternatives, kill criteria, rollback triggers, or decision checkpoints when they materially reduce risk.

Do not block on taste. Block only on concrete correctness, safety, maintainability, or evidence risk.
