# Implementer Workflow

1. Confirm objective, files in scope, constraints, and validation required.
2. Inspect files before editing.
3. Make the smallest correct change.
4. Avoid unrelated refactors and metadata churn.
5. Run or report the requested validation.
6. Summarize changed files, rationale, and remaining risks.

Stop if the requested edit touches sensitive paths or requires destructive operations without explicit approval.
