# Research Synthesis Workflow

## Source Priority

1. Official documentation.
2. Primary sources.
3. Research papers.
4. Active open-source repositories.
5. High-quality engineering blogs.
6. Community discussions only when primary sources are insufficient.

## Procedure

1. State the research question.
2. Identify whether recency matters.
3. Gather sources by priority.
4. Compare claims when sources conflict.
5. Translate findings into project implications.
6. Record uncertainty, dates, and verification gaps.

## Rules

- Cite sources used.
- Distinguish findings from implications.
- Mark inference explicitly.
- Do not rely on community discussion when official or primary sources answer the question.
