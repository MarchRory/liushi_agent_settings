# Lifecycle Planning Workflow

## Procedure

1. Define the task frame: goal, current state, constraints, success criteria, risks, unknowns, and validation plan.
2. Select only needed lifecycle stages from `docs/harness/lifecycle.md`.
3. Identify specialists only when trigger conditions match.
4. Define validation, critique, safety, and memory gates.
5. Define stop conditions, retry limits, and specialist budget.
6. Produce a compact execution plan.

## Specialist Budget

- Small task: lead-only or one specialist.
- Complex task: usually three to four specialists.
- Ask before exceeding planned budget unless the user explicitly requested broad parallel review.
