# Lifecycle Planning

## Core Rule

Select only the lifecycle stages that improve the outcome. Process is a tool, not a default tax.

## Workflow

1. Read `references/workflow.md` for stage selection and gate design.
2. Use `references/output-schema.md` for the required execution plan.
3. Use `examples/standard-output.yaml` as a compact plan template.

## Resource Map

- `references/workflow.md`: task framing, stage selection, specialist budget, and stop conditions.
- `references/output-schema.md`: canonical `execution_plan` schema.
- `examples/standard-output.yaml`: minimal valid execution plan.
