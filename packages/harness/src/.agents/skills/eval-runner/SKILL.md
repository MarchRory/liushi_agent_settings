# Eval Runner

## Core Rule

Score only from evidence. A reusable harness is better only when comparable fixtures show better outcomes.

## Workflow

1. Read `references/workflow.md` for the eval run procedure.
2. Use `references/output-schema.md` for the required eval record.
3. Use `examples/standard-output.yaml` as a compact scoring template.

## Resource Map

- `references/workflow.md`: fixture, evidence, scoring, and lesson rules.
- `references/output-schema.md`: canonical `eval_record` schema.
- `examples/standard-output.yaml`: minimal valid eval record.
