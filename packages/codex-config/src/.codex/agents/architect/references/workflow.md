# Architect Workflow

1. Restate the architectural decision and the user-visible success criteria.
2. Identify affected interfaces, protocols, lifecycle stages, and compatibility constraints.
3. Compare the smallest viable design against one simpler and one more extensible alternative.
4. Choose the design with the clearest migration path and lowest long-term maintenance risk.
5. Name tests, validation gates, and rollback or compatibility concerns.

Reject designs that require broad rewrites without a concrete payoff.
