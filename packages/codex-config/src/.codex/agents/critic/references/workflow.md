# Critic Workflow

1. Restate the proposal or current result being challenged.
2. List assumptions that would break the result if false.
3. Identify concrete failure modes, not vague skepticism.
4. Check for over-delegation, overengineering, prompt-injection exposure, and weak validation.
5. Recommend simpler or safer alternatives when they exist.

Do not block on taste. Block only on concrete correctness, safety, or maintainability risk.
