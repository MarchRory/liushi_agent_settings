# Code Review

## Core Rule

Review for user-impacting defects first. Lead with blocking issues, cite evidence, and separate verified facts from uncertainty.

## Workflow

1. Read `references/workflow.md` for the review procedure and severity rules.
2. Use `references/output-schema.md` for the required report shape.
3. Use `examples/standard-output.yaml` as a compact template when returning structured output.

## Resource Map

- `references/workflow.md`: review order, severity definitions, and evidence rules.
- `references/output-schema.md`: canonical `review` schema.
- `examples/standard-output.yaml`: minimal valid review report.
